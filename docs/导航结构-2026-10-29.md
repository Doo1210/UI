## 对象与入口边界

- **智能体类型只保留专家和工作流**。对话流、单智能体、多智能体不再作为新版新建入口；存量对象的迁移与历史链接需单独处理。
- **高级功能**在总览底部并列展示智能体运行时、软件开发套件和低代码 UI 三个入口；侧栏均放在横线下方，不新增节标题。运行时保留组织开通和使用权限限制；软件开发套件和低代码 UI 未新增付费或审批限制。
- 总览三个高级功能入口统一先展示介绍页，强调适用人员、功能用法、交互示例和开始路径；顶部固定操作进入对应工作区。侧栏直接进入工作区的行为保留。
- **低代码 UI 是界面应用**，可在一个应用中绑定多个工作流。菜单从智能应用分区移至侧栏下方，避免重复入口。原型提供界面应用列表、页面预览和多选工作流绑定；正式版还需校验输入输出映射、版本与权限。
- **软件开发套件**提供开发指南和示例项目两个原型页签，内容为演示，不表示已有可下载的 SDK、代码仓库或生产 API 已开放。
- **能力中心**依次为模型中心、知识中心、资源库。资源库右侧页面提供“技能、MCP、插件、连接器”四个 Tab，默认显示技能，各自支持原型列表搜索；模型与知识库仍在独立中心管理。
- **智能应用洞察**是单一侧栏入口，右侧页面通过“观测、评测、评优”三个 Tab 切换，默认观测。观测覆盖专家和工作流执行链路与异常；评测展示测试集和评测任务；评优展示版本对比与优化建议。智能体运行时的 Pod、镜像与扩缩容仍在托管工作区，不混入业务质量洞察。
- **智能体运行时是组织级高级服务**。总览始终可查看介绍及开通状态；组织已开通且用户有权限时，业务导航底部出现“智能体运行时”入口，不设置“高级服务”节标题。
- **本体、视觉、时序、设计**是外部工业引擎，仅由总览四张卡片引导。已开通时点卡片主体进入专属侧栏，“查看介绍”进入介绍页；未开通时进入介绍与申请页。
- **事件中心**是主平台的单一菜单，事件引擎的操作归于此，不再另建同名工业平台入口。

侧栏主导航使用浅色静态节标题，节标题自身不展开收起；整条侧栏可在 180px 展开态和 60px 图标态之间切换，并记住选择。图标态以居中的柔和短横线标明分区，底部管理入口纵向单列排列，悬停图标立即显示名称。只有本体、视觉、时序、设计四个工业引擎进入专属二级侧栏。具体对象操作和筛选放页面内。底部管理按钮按角色与原型演示开关显示。

总览和资产广场保持在最上方，随后依次为“智能应用”和“能力中心”。事件中心、智能应用洞察、智能体运行时统一放在业务导航最下方，用一条浅色横线与上方分隔，不设节标题；它们随业务导航滚动，不改变底部固定用户区的毛玻璃衔接样式。
