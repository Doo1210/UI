# 万悟工业智能体平台侧边栏原型

基于《智能体平台侧边栏信息架构设计方案》实现的交互式前端原型，重点验证侧边栏信息架构、角色权限、组织切换及管理入口交互。

## 已实现

- 核心业务菜单与固定工具区
- 二级菜单展开及侧边栏收起模式
- 系统管理员、组织管理员和普通用户权限预览
- 平台运营、管理中心悬浮菜单
- 组织切换器与用户菜单
- 桌面端和移动端响应式布局

## 本地预览

```bash
npm install
npm run preview:local
```

打开 `http://127.0.0.1:4173/`。

## 校验

```bash
npm run lint
npm run build
```

仓库通过 GitHub Actions 自动部署到 GitHub Pages。
